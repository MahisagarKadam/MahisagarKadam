# 🔥 Featured Project  
## **Hearing Hand – Real-Time ISL Detection**
A real-time Indian Sign Language recognition system using:

- **YOLOv8** (custom trained)
- **MediaPipe Holistic**
- **OpenCV**
- Converts gestures → **instant on-screen text**
- Helps bridge communication gaps for deaf & hard-of-hearing users
